Couch multiplayer for gen1recomp

Three mods for gen1recomp. Play side by side on one screen, or see each other across a LAN.

Install from inside the game

MODS → Find mods → add an index, and paste:

moonfall-man/pokemon-couch-multiplayer

All three appear; install what you want, and they update themselves afterwards. The game ships with no index sources on purpose — adding one is a deliberate act of trusting whoever publishes it.

Prefer not to trust a feed? Use MODS → Import mod .zip with a file from Releases, or drag it onto the window. Same installer either way.

What's in here

PAD_OWNEROne controller per window — the piece that makes split screen possible at all. Completely inert unless POKEPORT_PAD is set, so it is safe to leave installed when playing alone.
GHOST_LINKSee the other players walking around your world, with their Pokémon hovering behind them. Presence only: nothing about your save is shared, and no ghost can block you.
PAD_HOTKEYSReach the display hotkeys from a controller instead of the keyboard.

You supply the ROM

Nothing here contains game data. The follower sprites are generated on first boot from the art the game already extracted from your own cartridge dump, and they live in your save folder. Nothing is downloaded and nothing is redistributed.

GHOST_LINK stays off unless POKEGHOST_HOST or POKEGHOST_JOIN is set — installing it never opens a socket on its own.
