Couch multiplayer for gen1recomp

Play side by side on one PC, on top of gen1recomp. One mod. Import it, set PLAYERS, load your save.

Install

MODS → Find mods → add an index, and paste:

moonfall-man/pokemon-couch-multiplayer

Then MODS → COUCH MULTIPLAYER → OPTIONS.. → PLAYERS: 2, quit, and open your save. The second window starts itself about a second later — its own save, its own controller, its own half of the screen.

It is the save that starts it, not the launcher's Play button: gen1recomp loads no mod code until a game is open, so nothing can happen while the launcher is still on screen. The window it opens boots straight into the game rather than showing a second launcher, so that one second is the whole wait.

Prefer not to trust a feed? MODS → Import mod .zip with the file from Releases, or drag it onto the window. Same installer either way. The game ships with no index sources on purpose — adding one is a deliberate act of trusting whoever publishes it.

What it does

Split screen2–4 players, separate saves and parties, one controller each. Real independent games side by side, not one window in quadrants.
See each otherA player on your map appears as a walking figure with their lead Pokémon hovering behind. Presence only: you cannot talk to, battle, trade with or block one another.
Pad hotkeysThe display toggles on the buttons the engine leaves free — both stick clicks, X and Y.

PLAYERS: 1 is the default and does nothing at all — no extra window, no controller filtering, no socket. Installing this and playing alone is indistinguishable from not having it.

It starts the other windows itself

Worth being explicit, because a mod that launches processes deserves scrutiny. The rules: only ever this game's own executable, found through love.filesystem.getSource(), never a path from a file or the network; a started window is told it is a child and a child never starts anything; once per session.

You supply the ROM

Nothing here contains game data. The follower sprites are generated on first boot from art the game already extracted from your own cartridge dump, and they live in your save folder. Nothing is downloaded and nothing is redistributed.
